# Frontend

React + Vite Dashboard mit Glassmorphism Design.

## Entwicklung

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Docker

```bash
docker build -t trading-frontend .
docker run -p 80:80 trading-frontend
```

## Features

- 📊 Echtzeit Bot-Status
- 📈 Signale-Übersicht
- 💼 Trade-History
- ⚙️ Konfigurations-Panel
- 🎨 Glassmorphism UI
